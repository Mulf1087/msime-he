# 小鹤音形与水杉原有功能共用

## 目的与基线

在 macOS 独立小鹤音形方案中逐步接通水杉已有的形码提示、候选释义和联网能力。已发布的 `v0.55.0-xiaohe-428597` 是回归基线：一至四码查询、静态候选次序、五项分页、分号次选、四码唯一自动上屏与第五键顶屏必须保持。`sm` 首选“什么”，`nirx` 首选“你”。不改变全拼、双拼或其他方案的默认值。

## 功能边界

| 功能 | 当前路径 | 小鹤音形的接法 |
| --- | --- | --- |
| 形码提示 | 拼音辅助码注释 | 从随包小鹤形码表计算候选注释；仅显示，不参与音形查表或筛选。第一阶段默认显示，后续提供独立开关。 |
| 英文释义与候选翻译 | Runtime 候选释义、Host API 翻译查询 | 打开音形候选的释义能力，沿用用户已有的离线释义和翻译开关；翻译只改变注释，不改变候选顺序或上屏文本。 |
| 云候选 | 拼音/日文在线查询 | 另加音形专用的显式授权。自定义服务可按原样编码及 `mode=xiaohe_yinxing` 查询；内置拼音服务只接受能无歧义转成拼音的编码。云行置于本地表之后，不能影响自动上屏、分号或第五键。 |
| 云端词库 | 账号词库与 WebDAV 个人词条同步 | 音形码表是带顺序的静态基线，不能写进拼音或快捷短语词库。新增可增删的音形用户覆盖层，以（编码、词）为身份记录变更；先接本地导出/回放与 WebDAV，再评估账号后端是否提供新词库类别。 |
| 其他水杉能力 | 标点、模式、候选操作、主题等 | 按是否只读展示、是否改变候选或提交、是否依赖拼音逐项核对；只读展示先接，改变音形输入规则的功能需独立开关和回归。 |

云候选与云端词库同步是两条不同路径。联网功能保持用户原有的选择和许可，不在新装时自动打开。对不支持音形编码的服务不发送四码形码，也不把个人词库放进在线查询。账号云词库的后端不是本仓库控制，不能声称新类别可用，须以真实 API 合同和端到端测试为准。

## 第一阶段：显示链

在 Engine 的音形会话里使用内置 `xiaohe_helpcode.txt` 建立独立的显示映射；保留原全拼、双拼使用的辅助码映射与筛选设置。注释只出现在音形普通表项，不给英文、插件、云占位等行附形码。资源缺失时正常输入，注释为空。Runtime 的 `shows_glosses` 对音形开放，翻译请求仍受现有偏好、来源过滤与网络授权控制。

第一阶段不改码表、候选排序、自动上屏、用户个人表和现有安装版。用合成码表及形码表测注释和候选次序，用翻译查询夹具测离线/在线开关。macOS 原生测试覆盖菜单、候选显示与输入持续性；通过后再打新的安装包并在隔离状态验收。

## 后续阶段与交付

第二阶段实现音形云候选的服务协议、代次隔离和本地排序保护；第三阶段实现音形用户覆盖层和 WebDAV 同步。每阶段单独提交与验证，保持已发布版本可下载。账号云词库、跨平台宿主及上游新版本同步另设兼容性检查，不用“编译通过”代替真实服务或编辑器验收。

用户提供的真实码表和本地配置留在源码仓库外。用户已经明确授权把当前 DMG 中的码表作为公开 Release 发布；后续源码提交仍只用合成测试数据，不把账号、历史输入和个人偏好纳入版本控制。
